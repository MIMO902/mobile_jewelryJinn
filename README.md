# JewelryJinn – Mobile App (Flutter)

Flutter UI for the JewelryJinn AI jewelry design platform – the mobile companion to the [web app and backend](https://github.com/MIMO902/AI-jewelry-Generation).

## Screens

Splash, welcome, login and register, home, generate design, edit design, saved designs, profile, and admin dashboard.

## Built with

Flutter / Dart, image_picker

## Run

```bash
cd smartjewelry
flutter pub get
flutter run
```

Status: UI prototype – screens are built; connecting to the backend API is the next step.
